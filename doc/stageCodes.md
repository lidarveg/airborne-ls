# Products and Stage Codes

Each of the following is a raster output, so quantities are calculated for each pixel. The
pixel sizes vary between products, as some are more suited to finer scales than others.

| Stage Code | Product Description                          |
| :--------: | :------------------                          |
|    bb0     | DEM                                          |
|    bb1     | Maximum elevation value for pixel            |
|    bb2     | Intensity of point return at maximum height  |
|    bb3     | Whether pixel has any ground returns         |
|    bb4     | Most common non-ground point classification  |
|    bb5     | Density of first returns                     |
|    bb8     | percentile1                                  |
|    bb9     | percentile5                                  |
|    bba     | percentile25                                 |
|    bbb     | percentile50                                 |
|    bbc     | percentile75                                 |
|    bbd     | percentile95                                 |
|    bbe     | percentile99                                 |
|    bbh     | Foliage Projective Cover                     |
|    bbi     | DEM hillshade                                |
|    bbm     | Canopy Surface Model                         |
|    bbn     | Canopy Height Model                          |
